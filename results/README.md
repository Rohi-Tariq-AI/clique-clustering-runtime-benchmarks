# Result schema

- `raw_runs.csv`: one timed execution per row
- `paired_runtime_effects.csv`: matched \(T_O/T_P\) and log-ratio
- `effect_size_summary.csv`: graph-density median ratio and log-IQR
- `aggregate_effects.csv`: density-specific and overall robust effects
- `execution_order_diagnostic.csv`: first-versus-second position check
- `validation_results.json`: methodological invariants
- `environment.json`: computational environment
